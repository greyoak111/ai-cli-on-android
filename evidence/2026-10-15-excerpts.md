## DeepSeek Harness：对本地 mock 端点跑完一个回合（不用凭据）

四道门依次出现、依次过掉：

```
# 1) 内部模块原生附件
dsh: host preparation failed: No usable native binding found for node-addon-require-builtin-android-arm64 (auto)
#    → 自己编（公开源码，一条 clang 命令）或 --expose-internals + JS 回退

# 2) 会话锁
dsh: flock is not supported on android-arm64
#    → bionic 里 flock(2) 是有的：koffi 调它（真锁），或退化为空锁

# 3) 硬链接（SELinux）
dsh: EACCES: permission denied, link '…/session.v4.jsonl.zstd.<hex>.tmp'
        -> '…/session.v4.jsonl.zstd'
#    → link 的"独占发布"语义不能换 rename，改 open(…, "wx")

# 4) 凭据
dsh: MISSING_CREDENTIAL: llm-deepseek: no API key for provider route "deepseek-official"
#    → 给个假 key，把 DEEPSEEK_BASE_URL 指向本地 mock
```

然后：

```
$ dsh --profile headless "reply with the word ok"
OK-FROM-LOCAL-MOCK            （rc=0，stderr 为空）

$ cat mock.log                 （mock 端点收到的真实请求）
```

web profile 同时可用：

```

$ curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:3080/            → 401
$ curl -s -o /dev/null -w '%{http_code}' "http://127.0.0.1:3080/?token=…"  → 303
```

硬链接这一条可以脱离 DSH 单独复现（是安卓本身的行为）：

```
$ echo x > a; ln a b
ln: failed to create hard link 'b' => 'a': Permission denied
$ mv a c          # 同目录 rename 正常
```
